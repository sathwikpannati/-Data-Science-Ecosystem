# Data Science Tools and Ecosystem

A short Jupyter notebook summarising the main languages, libraries and tools used in data science, with a few simple Python examples.

> Completed as the final assignment of the **Tools for Data Science** course (IBM Data Science Professional Certificate, Coursera).

## Contents

The notebook [`DataScienceEcosystem.ipynb`](DataScienceEcosystem.ipynb) covers:

- **Languages:** Python, R, SQL, Java
- **Libraries:** NumPy, pandas, Matplotlib, SciPy, TensorFlow
- **Tools:** Hadoop, Apache Spark, TensorFlow
- **Python basics:** arithmetic expressions and a unit conversion (minutes to hours)

## How to run

```bash
pip install jupyter
jupyter notebook DataScienceEcosystem.ipynb
```
